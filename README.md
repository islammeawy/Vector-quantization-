# Vector Quantization Image Compression

## Member 1 interface

Use `generate_preprocessing_and_codebook()` from `codebook_generator.py`:

```python
from codebook_generator import generate_preprocessing_and_codebook

result = generate_preprocessing_and_codebook(
    "image.png",
    block_height=4,
    block_width=4,
    k=16,
)
```

The returned dictionary contains:

- `codebook`: NumPy array with shape `(K, Bh * Bw)`.
- `vectors`: NumPy array with shape `(N, Bh * Bw)`, ordered row-major.
- `original_shape`: `(original_height, original_width)`.
- `padded_shape`: `(padded_height, padded_width)`.
- `block_height`: block height `Bh`.
- `block_width`: block width `Bw`.
- `num_vectors`: number of extracted vectors `N`.
- `num_codewords`: number of codewords `K`.

For encoding, process `vectors` from left to right and top to bottom, and compare each vector to `codebook` using Manhattan distance.

For reconstruction, place each encoded codeword in row-major block order using `Bh` and `Bw`, reshape each codeword to `(Bh, Bw)`, and crop the reconstructed array to `original_shape`.

Member 1 only provides preprocessing and codebook generation. It does not perform encoding, binary file writing, decompression, or compression-ratio calculation.

## Member 2: Encoding

### Overview

The encoding module converts the preprocessed image vectors into codebook indices using Vector Quantization. Each image vector is assigned to the closest codeword in the generated codebook using the Manhattan (L1) distance.

### Encoding Process

1. Receive the vectors and codebook generated by the preprocessing and codebook-generation module.
2. Calculate the Manhattan distance between each image vector and all codewords.
3. Assign each vector to the codeword with the minimum distance.
4. Save the codebook and assigned indices into binary files for use during decompression.

### Implementation

The encoding module is implemented in `compression.py`.

- `assign_vectors(vectors, codebook)`: assigns each vector to its nearest codeword using L1 distance.
- `save_codebook(codebook, block_height, block_width, path)`: serializes the codebook and its metadata into a binary file.
- `save_compressed(indices, metadata, path)`: serializes the image metadata and encoded indices.
- `encode(data, output_dir=".")`: coordinates the encoding process and saves the binary output files.

### Output Files

The encoder generates two binary files:

| File             | Description                                               |
| ---------------- | --------------------------------------------------------- |
| `codebook.bin`   | Contains codebook metadata and codeword values.           |
| `compressed.bin` | Contains image metadata and the encoded codeword indices. |

The files are generated inside the specified output directory, which is created automatically if it does not exist.

### Binary Format

#### Codebook File (`codebook.bin`)

| Field                   | Data Type                    | Description                              |
| ----------------------- | ---------------------------- | ---------------------------------------- |
| Magic identifier        | 4 bytes                      | `VQCB`                                   |
| Number of codewords (K) | 32-bit unsigned integer      | Codebook size                            |
| Vector dimension        | 32-bit unsigned integer      | Number of values per codeword            |
| Block height            | 32-bit unsigned integer      | Height of image blocks                   |
| Block width             | 32-bit unsigned integer      | Width of image blocks                    |
| Codebook data           | 64-bit floating-point values | Codeword vectors in little-endian format |

#### Compressed Image File (`compressed.bin`)

| Field                   | Data Type                         | Description                                |
| ----------------------- | --------------------------------- | ------------------------------------------ |
| Magic identifier        | 4 bytes                           | `VQIM`                                     |
| Original height         | 32-bit unsigned integer           | Original image height                      |
| Original width          | 32-bit unsigned integer           | Original image width                       |
| Padded height           | 32-bit unsigned integer           | Height after padding                       |
| Padded width            | 32-bit unsigned integer           | Width after padding                        |
| Block height            | 32-bit unsigned integer           | Block height                               |
| Block width             | 32-bit unsigned integer           | Block width                                |
| Number of codewords (K) | 32-bit unsigned integer           | Codebook size                              |
| Number of vectors       | 32-bit unsigned integer           | Total encoded vectors                      |
| Index byte width        | 32-bit unsigned integer           | Number of bytes used per index             |
| Encoded indices         | Variable-length unsigned integers | Codebook indices in row-major vector order |

All metadata fields are serialized in little-endian byte order. Encoded indices use 1, 2, or 4 bytes depending on the codebook size.

### Initial Test

The encoder was tested using a 320 × 240 image, with a block size of 4 × 4 and a codebook size of 16.

| Test Result               |       Value |
| ------------------------- | ----------: |
| Original image dimensions |   320 × 240 |
| Block size                |       4 × 4 |
| Codebook size             |          16 |
| Total vectors encoded     |       4,800 |
| Minimum index             |           0 |
| Maximum index             |          15 |
| Codebook file size        | 2,068 bytes |
| Compressed file size      | 4,840 bytes |

The initial test successfully generated both binary files, and all 4,800 encoded indices were within the valid codebook index range (0–15).

*Note: These are preliminary test results and do not represent the final compression-ratio evaluation.*
